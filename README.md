# Pikay Tool - Automation

Phần mềm tự động hỗ trợ các nghề trong Rlife trên Windows.

Tải bản chính thức tại [GitHub Releases](https://github.com/pdphua25005/Pikay_tool_automation/releases/latest).

Giải nén ZIP, mở EXE và nhập key được cấp. Nhấn **7** trong Rlife để kết nối, **9** bắt đầu, **0** dừng. Chọn nghề và xem hướng dẫn ghi tuyến trong tool.

Ứng dụng yêu cầu Internet để xác thực giấy phép và kiểm tra bản cập nhật có chữ ký. Dữ liệu người dùng lưu riêng tại `%USERPROFILE%\AutoFarmData`.
